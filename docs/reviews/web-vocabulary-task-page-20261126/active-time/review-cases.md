# 活跃计时独立复核用例

本次口径由用户选择：页面可见且最近 5 分钟内有人为操作，累计本端活跃时间；刷新保留，后台/离页不补记。它是一个带 5 分钟空闲宽限的估算，不是逐秒证明正在学习。

独立探针只调用实际计时器与事件接线，不修改产品，不访问服务器/学生数据。最终执行结果写入同目录脚本及日志；本清单本身不代表已经通过。

1. 17:00 学习 10 分钟，正常 pagehide，22:00 恢复再学习 15 分钟：累计约 25 分钟。
2. 可见但无操作超过 5 分钟：只计前 5 分钟，随后操作从当前时刻开段，不补空闲间隔。
3. 隐藏后发生输入、后台同步或页面恢复：隐藏区间不计，恢复不回填。
4. 同 task/student 的重叠标签页区间取并集；不同 task/student/review session 互不串记。
5. 旧标签晚刷区间、任意 checkpoint 顺序不使重叠时间重复；storage 写失败后恢复保留本地真实区间。
6. 首次 settle 快照冻结；重试/刷新/其他标签不增加等待时间；incomplete 的恢复从新代际开始点继续；已 complete 不再增长。
7. blocked、future、read-only、result、保存失败均不因自动响应/刷新续命；review session 切换时旧 session 停止累计。
8. v1 wall-clock 未结算记录不伪装成活跃分钟；已发 pending settle payload/服务器已结算结果保持原语义。
9. 真实键盘、输入法、点击/触控、用户滚动唤醒；程序 render/focus/滚动、轮询与长按重复事件不无限续命。
10. 无存储、损坏记录、时钟回退/前跳以保守方式处理，不出现负数或凭空的大时长。

不把假时钟/模拟 visibility 或重建客户端内存称为原生浏览器、真实关机、断网或跨设备验收。
