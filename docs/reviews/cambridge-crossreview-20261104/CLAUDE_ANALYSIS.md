## 4. 分歧的主要成因

1. **阅读解析的标注范围被截短。** 这是最大的一类。
   - 从句边界题“答案错”583 道中，有 517 道的复核答案和解析器划出的完整从句一模一样；完整主语题 271 道中有 266 道一样。
   - 从句类型题有 759 道“高亮不全”，从句边界题有 100 道范围不全。
   - 这些截短也会显示在阅读页上。
2. **不定式、分词被标成从句。**
   - 动词身份题：140 道应为“非谓语”；
   - 从句类型题：133 道应为“不是从句”；
   - 状语关系题：124 道题干前提不成立（目标不是状语从句）；
   - 另有 263 道判为歧义。
3. **共用主语的并列谓语被当成并列分句。** 从句类型题 128 道，例如 `... are complex and vary widely` 里的 `vary widely`。
4. **so / for 引出的分句。** 复核按并列分句处理：
   - 30 道从句类型题应为“并列分句”；
   - 43 道动词身份题应为“主句谓语”；
   - 另有 217 道判为歧义。
5. **完整主语多带了成分。** 带了插入语（he proposes、however）或句首副词（Perhaps）；引语句的主语按 says 那一句算（复核口径）。
6. **答案不唯一。**
   - 冒号、分号两侧各有主句：201 道；
   - 句中有多个同类从句：169 道。
7. **原句问题：35 句、96 题。**
   - 32 句是剑桥原文本身的写法，例如逗号连接两个分句、悬垂分词、主谓一致。原文改不了，只能不出题。
   - 3 句是录入错误：
     - ielts13_test3_p3 E-04：破折号录成汉字“一”；
     - ielts9_test4_p1 E-04：段末断在 `the chemist André`；
     - ielts9_test2_p2 F-03：`today's value of methods in accuracy` 读不通，像是中间丢了字。

     后两处要对照原书补，不凭记忆补。

## 6. 需要用户决定

1. **判正确的 2,457 道是否放行。**
   - 建议：记作“交叉复核通过”，与机器自动通过分开统计；老师盲审时仍可抽查。
   - 放行后剑桥可用题从 27,633 道增至 30,090 道。
2. **1,246 道改答案怎么落地。**
   - **快速做法：** 按题号把复核结论写成一份复核记录，出题器读取后改答案、改状态。记录里存每道题当前内容的指纹，题目一变，记录自动失效。
   - **根治做法：** 修阅读解析的标注，包括截短的范围、被当成从句的不定式和分词。阅读页的显示也会一起改对。工作量大，修完要重新复核。
   - 建议先用快速做法拿到可用题，根治放到下一阶段。
3. **口径问题。** 定了以后才能按规则统一处理：
   - so / for 引出的分句：建议按**并列分句**处理，与现在 for 的规则以及复核意见一致。影响 30 + 43 道改答案，以及 217 道歧义题。
   - 省略状语从句（when applied、if sustained、while doing）：动词身份题里的分词按非谓语（复核如此判）；从句边界题、从句类型题建议不出这类题。
   - 直接引语加 says：语法上 says 那一句是主句。为避免学生困惑，建议这类句子不出主句谓语题和完整主语题。
4. **3 处录入错误是否修原文。** 两处需要你对照原书提供原文。
5. **剔除的 1,574 道。** 建议直接从候选池里拒绝掉，不再保留在待复核里。

## 7. 自动通过池

这次复核只覆盖待复核题。上面几类系统性问题（边界、类型、限定性与解析不一致）正是出题器会拦下的，所以自动通过的 27,633 道都过了这些检查。

但自动通过池还没有经过独立的整体复核。上线前建议：
- 从剑桥自动通过池每种题型抽 100 道（共 600 道），用同样的方式交叉复核一次，量出自动通过题的实际错误率；
- 或者用老师盲审表（剑桥 233 行）先做。
