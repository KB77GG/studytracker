## Semantics
Shanghai natural dates. Formal error -> next date. Two independent review successes separated by >=2 natural dates close mandatory queue. Same-date repeat never advances success or failure streak. New error resets success. Three consecutive different-date review failures pause7 days; reentry resets failure streak, retains events. Source learning error opens queue but does not consume one of the three delayed review rounds.
If a new task error occurs after today's review slot was issued, the eventual slot answer still completes the slot and records its outcome, but cannot advance the next-day error assessment early.
Mandatory daily allocation <=20 including at most4 checkpoints; missing checkpoints release quota to errors; no extra checkpoint fill above4. Today due errors precede 1..7-day overdue, stable tie order. Only when current demand exceeds remaining capacity are >7-day error rows transferred to maintenance with overdue_overload event; otherwise still eligible. Checkpoints not selected by their target date become missed, never counted as nominal D7/D30 recall later.
Optional <=10, no gate; adapter reuses existing due eligibility/materialization. Reserved slots count toward daily capacity, answered/skipped toward completion. No old mastery changes by core; integration continues authoritative old answer-state bookkeeping. Defaults OFF preserve old routes byte-for-byte.
