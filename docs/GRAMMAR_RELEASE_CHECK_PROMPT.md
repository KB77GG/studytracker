> 用法：
> 1. 先把下面“提示词”整段发过去。
> 2. 再依次上传 `release_check_001.csv` 至 `release_check_006.csv`。
> 3. 输出格式与上次待复核题的复核相同，交回后按“题目编号”合并。
>
> 文件由 `scripts/select_grammar_release.py` 生成（种子 20261104）：

> - 抽查 593 道：主句谓语、从句边界、从句类型、完整主语、动词身份各 100 道，状语关系 93 道（全部）。
>
> **建议的验收标准（待用户确认）：** 每种题型的抽查题里，“答案错”“题目有歧义”“句子不适合出题”合计不超过 2 道（≤2%），该题型才上线；超过的题型先不上，找出原因后调整。

## 提示词

你是英语语法专家，帮我验收一批自动生成的英语语法练习题。题目来自剑桥雅思阅读原文，给中国学生用，术语按国内常见的传统语法口径。

这批题都已通过出题程序的自动检查，准备上线。这次抽查是为了量出它们的实际正确率，所以请严格、独立地判断，不要因为它们已通过检查就放松。口径与上次复核待复核题时保持一致。

### 每道题的字段

- **题型**：见下文“六种题型”。
- **题干**：学生看到的题目要求。
- **句子（【】标出目标）**：分类题里，【】标出要判断的部分。
- **选项**：选择题的选项。
- **机器答案**：
  - 选择题：给出的是选项。
  - 点选题、划范围题：在原句里用【】标出答案。
- **判分说明**：只有主句谓语题有，见下文。
- **干扰项**：主句谓语题里程序认为容易误点的词。

### 六种题型

1. **主句谓语**：学生点出整句主句的谓语动词。
   - 机器答案连同助动词、否定词一起标出，例如【will be needed】。
   - 学生点出的词只要包含“判分说明”里的那个词就算对。
   - 请判断：这个词是不是主句谓语的核心；有没有别的同样合理的答案；干扰项是否确实不是主句谓语。
2. **从句边界**：学生划出指定的从句，从第一个词划到最后一个词，忽略标点。
   - 定语从句、名词性从句、状语从句：句中如果还有另一个同类从句，题目就有不止一个答案，应判“题目有歧义”。
   - 并列分句：题干写明是哪个连词后面的分句，学生划的范围包不包含这个连词都算对。
3. **从句类型**：判断【】部分是定语从句、名词性从句、状语从句、并列分句，还是“不是从句（短语或非谓语）”。
   - 按传统口径：有限动词构成的从句算从句。
   - 不定式、分词、动名词结构，以及介词短语，算“不是从句”。
4. **状语关系**：判断【】标出的状语从句表示什么关系，选项是时间、原因、条件、让步、对比、目的、结果。
   - 如果【】部分其实不是状语从句（例如介词短语、不定式），题干前提就错了，应判“答案错”或“题目有歧义”，并在说明里写清楚。
5. **完整主语**：学生划出整句的完整主语，包括修饰它的成分。
6. **动词身份**：判断【】里的动词是“主句谓语”“从句里的谓语”，还是“非谓语（不定式、分词、动名词）”。

### 判定（只能四选一）

- **正确**：题目清楚，机器答案对，可以直接用。
- **答案错**：机器答案不对。在“正确答案应为”里写出正确答案：
  - 选择题写选项；
  - 点选题、划范围题写出英文原文片段。
- **题目有歧义**：不止一个合理答案，或者题干说不清，或者题干前提有问题。
- **句子不适合出题**：原句残缺、有排印错误、太偏，或者和这个知识点无关。

### 要求

- 逐题判断，一题都不要跳过，顺序与输入一致。
- 不要改写原句。
- 拿不准时选“题目有歧义”，在说明里写明哪里拿不准。
- “说明”用中文，40 字以内。判“正确”时可以留空。

### 输出格式

只输出一个 CSV 代码块，表头固定如下，每题一行：

```
题目编号,判定,正确答案应为,说明
```

CSV 后面另起一行，写本批各判定的题数，例如：正确 62 / 答案错 15 / 题目有歧义 20 / 句子不适合出题 3。
