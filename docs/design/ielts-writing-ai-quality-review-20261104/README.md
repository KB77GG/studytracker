## 需要修正的8项（P2）

### 1. 关键词重合度不能直接决定切题

`rewrite_quality.py:prompt_coverage/check`：同义表达充分回应gap-year利弊的280词作文，只有33.3%关键词覆盖，被判off_prompt；题干附上考试时间/字数说明后降至28.6%。反过来，在原来的离题在线教育稿前加一句含交通关键词的话，覆盖75%，整篇却被标为quality_passed=true。

这不是把阈值40%再调低就能解决：正例和反例的排序已经反了。建议先把词面覆盖作为不确定提示，别单凭它判质量失败或成功；主题/问题回应另用可验证结构或经过多题材正负样本验证的判断。考试指令也不应参与题意关键词分母。

### 2. 诚实的否定说明被反向判违规

`rewrite_quality.py:DATA_CLAIM_RE/check`：缺图时写“无法确认数据准确”“不能保证数据正确”都触发data_claim，导致无意义重试与质量失败。应识别否定/不确定语境，保留诚实限制说明；补正负对照而非仅补单个字串。

### 3. 大小写修改被误删为没改

`rewrite_quality.py:_norm/_change_problem`：合法的“i partly agree”→“I partly agree”，新写法就在正文，仍因.lower()被判noop_change，删除后又触发no_changes。比较“改动是否发生”应保留大小写（也要避免把有效标点修改归零）；文本查找规范化和改动等价判断不能共用这一宽松规则。

### 4. 字数白名单继续放过虚报

`rewrite_quality.py:_count_claim_ok`：实计290词，说明“改写稿共330词”，检查通过，因为330在上限白名单里。数字等于目标上限/下限，不代表当前稿件实际就有这么多词。需要区分谈目标、谈原稿和宣称当前稿字数；当前稿计数以服务器结果为准。

### 5. 中文达分声明漏检

`rewrite_quality.py:BAND_CLAIM_RE`：“本篇已达到雅思写作7分标准。”通过质量检查。当前正则仅覆盖Band/分数段等写法，而中文解释是工具的正常输出语言。应覆盖常见中文分数表达并保留否定/目标语境；仍不能把任何形式的模型自述当独立评分验证。

### 6. Task1虚构引文能触发确定的矛盾结论

`review.py:197–205`：注入不存在的Country Z/999%引文，系统正确得到quote_found=false，却仍添加“作文里有前后矛盾的数据或比较”的确定警告。未经原文核实的引文不能支持该结论；应丢弃或明确保留为未核实的模型猜测，不能升级成已确认发现。

另应明确能力范围：consistency_issues是模型返回的可选字段，不是确定性数值关系校验；旧矛盾稿不返回该字段就得到空列表。离线人工补字段只验证字段接收，不证明模型实际发现矛盾；这点要在下一批真实验证中检查。

### 7. 第二次调用出错会丢掉首稿

`review.py:377–408`：先返回可展示但质量不通过的247词稿，重试遇到timeout/truncated/http503，整体变failed/result=null；连max_calls=1、第二次被预算阻止的场景也丢掉首稿。原因是client.complete在处理best的异常保护外。

已有首稿时，重试传输/预算失败应返回首稿并显示“质量未通过”和重试失败原因；没有任何首稿才返回生成失败。预算不允许为保稿再发第三次请求。

### 8. “最终质量通过率”的分母不适合90%验收

`realcheck.py:_refine_rewrite_metrics`：7篇中1篇合格、6篇生成失败，final_ready=14.3%，但rewrite_quality_passed=100%，因为分母只计有result的稿件。数学上这是“已生成结果中的通过率”，不能直接充当全部样本最终通过率。
