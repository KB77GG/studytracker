## 给Claude的具体调整依据

1. **字数下限目前只是软警告。** `t2-mid`改写247词，`t2-under-length`改写220词，均低于Task2的250词；两者结果已有warning但仍ready。`normalize_rewrite`只在少于60词时拒绝，因此自动“生成成功100%”与“改写达标71%”不矛盾。需要明确是否把150/250下限纳入现有一次校验重试，或单列“生成完成但质量未通过”。不要直接隐藏warning或放宽字数要求。
2. **改动说明虚报长度。** `t2-under-length.key_changes`说“扩展到约270词”，实际服务端计数220；`band_rationale`还声称“已稳定符合Band 7标准”。字数展示应以服务端结果为准，目标分数不能当成已经实现的分数。
3. **离题改写的目标分数声明不可靠。** `t2-off-topic`仍写在线教育，题目却是交通投资；保留原论点符合当前保留立场策略，但rationale声称整体达到Band7。应明确离题条件下重写范围，并保留任务回应限制。
4. **Task1原文内部矛盾未被发现。** `t1-no-image`没有新造数字，但仍同时说“A两年最高”和“2020年C约80%、A约75%”；这个矛盾原稿已有。缺图不妨碍检查文本内部比较与数值是否一致，且不能据此声称数据已核实。
5. **Task1改动说明与正文不符。** key_changes说删除结尾总结段，正文仍有`In summary`；还有`had grown→had grown`这样的无实际改动说明。rationale说“满足Band7/数据引用准确”，与缺图限制和内部矛盾不相称。应让说明对应真实修改，减少无依据的自我评价。

这些是模型内容质量问题；本轮没有自行修改提示词再跑第二批。建议先离线增加上述真实输出回归场景，再商定下一批验证范围。7篇合成样本不能代替20–30篇教师评分校准，也不证明长期100%合格。
