## 人工审阅：真实引文仍可支持错误判断

以下是对合成原文的人工审阅，不是认证考官评分；完整逐条证据在 `manual_argument_review.json`。

1. **部分同意被误判为自相矛盾。** 弱作文开头为部分同意，正文明确公共交通更重要，结尾也先说公交应获得更多经费、必要时仍修路。模型只抓住最后的“双方都重要”，将其列为结尾不一致，并把道路段列为偏离。表达可以更清晰，但“优先一方”与“另一方仍有必要”并不互相否定。
2. **强作文反馈自身矛盾。** position.consistent=true，结尾段评论也说“结论与立场一致”，但问题列表又给出conclusion_inconsistent，理由只是结尾没有再次列出农村/货运例外。结尾的“lion's share”仍表达大部分资金，而非禁止所有道路投资。
3. **把可进一步展开，升级成没有论据。** 强文已经解释诱发需求以及“车站周边密度/步行便利→出行距离减少”，模型仍称没有机制或结果，并机械要求具名城市实例。中等作文的农村/货运例外也与有限定的立场相容，却因没有立即反驳而被列为concession_unanswered。可建议加强衔接，不应自动判成论证矛盾。
4. **建议加入了未给来源的具体数字。** 中等作文的建议直接给出“人均排放降低80%以上”；原稿没有这一数字，也未提供核实依据。本次没有证明该数字必然错误，但不能把无来源的精确数字当作改进论证的标准答案。

官方评分描述关注立场、观点展开与支持、逻辑衔接；官方备考说明允许用自身知识和经验举例，并明确提醒不要编造统计和研究。本次审阅据此建议把“论点→机制→例子→结果”用作诊断工具，允许不同的有效展开方式，不能把固定模板的每一格都变成必填条件。[官方Writing评分描述](https://ielts.org/cdn/ielts-guides/ielts-writing-band-descriptors.pdf)、[官方题目理解指南](https://ielts.org/news-and-insights/ielts-writing-task-2-how-to-understand-ielts-question-prompts)。

不要简单提高“强文最多1条”的阈值来让报告变绿。优先区分“确有矛盾”“支撑不足”“可选优化”；判前后矛盾时同时列出冲突的两处原文，并复核是否真有逻辑冲突。这不要求强作文完全不能被批评。

## 同批发现的其他边界

- **Task1仍漏报已知自相矛盾。** 原文说A两年最高，但又说2020年A约75%、C接近80%并超过A；原始输出明确返回 `consistency_issues: []`。不需要题图也能识别这处文内冲突，但本次模型仍没识别。
- **Task1解释语言不符合约定。** 21个模型解释字段全部英文、没有中文字符，尽管提示词要求简体中文。现有校验检查字段和证据，没有检查解释语言。
- **“各段”与原始分段不完全对应。** 97词样本只有1个物理段落，模型输出5个paragraph条目；其余5篇Task2都是原文5段、输出5条。当前没有段落编号绑定，页面可能把逻辑片段误当原始段落。可由服务端给段落ID，让模型引用ID并区分段内角色。
- **两个非阻断报告显示问题。** 全部Task2失败时Markdown省略论证统计节，JSON仍保留拒绝数；评价专用批次的改写检查应显示未运行，而不是自动通过。本次评价有效检查口径已经在上表说明，原始自动报告没有篡改。
