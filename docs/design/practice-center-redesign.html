练习中心改版稿

学生访问 /practice 时的新布局：今天的任务在最前，题库按科目成架，身份、模考和做题记录放右栏。与剑雅目录、写作题库共用 Sage Path 顶栏。老师视角不变。示例数据均为样例。

studytracker.xin/practice1280

修掉的问题

  • #1学生端不再渲染老师的筛选侧栏、预览面板和“布置给学生”
  • #2确认身份后只留身份胶囊，不再同时显示输入框
  • #7练习中心不再有指向自己的“返回练习中心”
  • #8去掉无效的资源类型、考试系列复选框
  • #12页头与剑雅目录、写作题库同一套

布局

  • 桌面：左栏约 880px 放任务和题库，右栏 320px 吸顶；首屏能看到全部今日任务和题库入口
  • 任务保留“老师布置作业 / 助教推送教辅刷题”两组；每行一个主按钮，状态用文字胶囊
  • “尚未开放”“已完成”折叠在任务卡片底部，与现有分组语义一致
  • 手机：单栏，科目导航横向滚动，任务按钮固定在每行右侧

实现提示

  • 学生端拆成 practice/student_center.html，staff 继续用原模板，避免互相影响
  • 数据全部来自现有接口：/api/practice/tasks、/api/practice/identity、模考与做题记录接口；题库计数沿用 _practice_library_summary()
  • 不依赖 Bootstrap 和 Font Awesome CDN；图标用内联 SVG
  • 词汇任务行是网页背词上线后的样子，开关关闭时不出现
