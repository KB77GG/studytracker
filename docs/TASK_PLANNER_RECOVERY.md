# 未完成收件箱与补做恢复

收件箱整合在“任务安排”页，跟随学生筛选，独立于未来日期和安排状态筛选。范围是该工作台学习线已发布的作业；普通任务管理里的临时作业不自动猜测归属。昨天及更早仍未处理的未完成任务保留在待处理列表，按学生、学习线、原任务日期分组。

原任务到次日北京时间03:00才截止；00:00–02:59:59仍在学生宽限期内，不进入待处理收件箱，也不能提前补做或忽略。03:00起可由助教处理；更早已截止的积压任务不受当天宽限期影响。自动布置仍从03:05开始，宽限期内正常提交的原任务可按既有规则继续计划。

## 助教的两个选择

- **安排补做并顺延**：把本组未有效完成的任务作为今天的新补做任务布置；同一学习线尚未发布的新内容整体后移，最早落到明天。若有早于今天的未发布内容，一并保留顺序后移，不丢题。原任务及成绩不变。按天顺延会改变原先的星期分布，必须核对预览中的原日期→新日期；顺延后实际日期以每天详情为准。
- **忽略本次，继续原计划**：明确放行这次未完成，不把原任务改为已完成，也不永久关闭学习线的等待规则。今天可发布的原安排会重新校验；过期未发布条目的处理和影响在预览中列明。后续仍按原规则检查下一学习日的任务。

每次只影响选中的学习线，不改其他学习线或学生自动布置开关。执行前显示具体补做内容、日期变化及阻止执行的原因，助教核对后再确认。今天本线已经发布了新任务时，不能再承诺“今天只补做”，补做顺延会被阻止；不撤回学生正在做的作业。

## 与原来的等待规则配合

选择“等待上一学习日全部任务有效提交”的学习线，前日未完成后进入待处理，助教可通过收件箱决定补做或放行。选择“仍按日期布置后续内容”的学习线继续原行为；收件箱不会擅自暂停这类安排。

补做与原任务有明确关联，重复点击或网络重试不会重复生成任务、重复顺延。后续等待会检查新补做的真实完成/提交情况；补做仍未完成时，下一天重新出现待处理提醒。词汇需要对应学生的有效结算，退回/部分通过不算完成。

只有这次明确选择补做的原任务及其补做祖先可豁免历史重复检查。其他已布置内容、其他学习线和待发布内容仍受重复保护；无关的资源下线、身份或重复冲突不会因为点击“继续”而自动消失。

## 发布和验证

实现、验证及部署状态以 CODEX_HANDOFF.md 顶部为准。新增独立处理记录表，保留处理人、请求标识、明确的源任务关联和日期调整记录；不修改旧任务/成绩列，不发送微信通知，不调用外部收费服务。

验收需要覆盖：默认继续与等待两模式、当日补做/忽略、跨日再次补做、词汇结算、阅读单篇剩余与整套完整性、日期/冻结快照一致、其他任务重叠、已发布保护、重复请求与并发、跨天过期预览、故障回滚、权限/CSRF、桌面和手机界面。
