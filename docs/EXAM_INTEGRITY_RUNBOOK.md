# 雅思模考诚信模式：老师故障处理手册

第一期仅覆盖网页 `/exam/...`；托福不在范围内。2026-11-15 的考试继续使用当前线上版，本开发版未部署。入口：模考列表／考生列表 → **监考 / 防作弊**。学生设备准备页 `/exam/guide`；在线简版手册 `/exam/integrity-help`。

## 开考前

默认关闭，未手动开启的场次没有守卫脚本。第一场真实模考用“仅记录”：记录行为但不锁定、不绑定设备、不拦粘贴。完成下面的真机试考后再考虑“警告并锁定”。开关变更不改成绩、不暂停计时。

打开监考面板后先确认场次，检查网络，向学生说明规则。阈值默认为累计离开 3 次或 60 秒，不到 2 秒的短暂隐藏不计次。听力只记录和警告，不锁定；阅读和写作可锁定。章节跳转不计次，窗口失焦、视口变窄、心跳中断都只是软信号。记录用于核查，不是自动认定作弊。

## 现象 → 怎么办

| 现象 | 怎么办 |
| --- | --- |
| 学生屏幕显示已锁定 | 在监考面板找到该生点“解锁”。页面正常联网时几秒内恢复，不需要刷新。计时和到时自动交卷仍继续。 |
| 学生说没有离开却被锁 | 先解锁，再看时间线和设备表现。必要时点“本场豁免”，考后再排查。 |
| 解锁后再次锁定 | 解锁不清零；之后新增一次有效离开或新增累计 30 秒可能再锁。老师可设置本场豁免。 |
| 提示已在另一台设备开始 | 确认是本人后点“允许换设备”，让旧设备关闭考试页面，新设备刷新。无痕模式和清缓存也可能造成设备标识变化。 |
| 显示“点击继续答题” | 点击继续或重新获得焦点即可。这个软提示不算一次离开，听力不盖该遮罩。 |
| 遮罩不消失或卡住 | 先解锁／豁免并确认网络。阅读写作确认保存后可刷新；听力先联系老师，避免刷新中断不可重播的音频。断网时不要立即刷新或关页面。 |
| 多人同时异常 | 点击红色“紧急关闭本场防作弊”。正常联网、页面可见时 20 秒内全部撤罩；隐藏页回到前台立即查询。诚信接口超时也会放行。 |
| 面板打不开 | 不影响学生原有考试接口。联系维护人员，考后排查；不要自行重启。 |
| 学生断网 | 保持页面，恢复网络后查看原有保存提示。不要清缓存、换无痕或关闭页面。各科沿用原保存机制；最近输入未必已经同步到服务器。 |
| 复制或粘贴被拦 | 题干不能复制，输入框内复制仍允许。作文仅允许粘回当前页作文框最近复制／剪切的原文；跨设备或刷新后会失去这个本页记录。只记录拦截长度，不上传剪贴板正文。 |
| 希望保留日志但撤掉限制 | 改“仅记录”；若只处理一名学生，用“本场豁免”。 |
| 需要彻底停用 | 先按各场“紧急关闭”；全局硬开关需要维护人员操作，见下方。 |

学生遮罩按规则提示“答案已保存”。此提示表示诚信功能不删除答案，**不是每次击键已成功上传的回执**；断网时以原页面实际保存状态为准。不要向学生保证未同步的输入已经在服务器。

## 维护人员：全局硬开关（这里只是操作说明，本轮未执行）

**必须先取得用户部署许可并确认没有正在进行的模考。** 重启会短暂中断服务，优先使用面板紧急关闭。由服务器维护人员在生产服务器执行，下列 drop-in 仅设置环境变量，不改既有 worker/threads/端口：

```sh
sudo install -d /etc/systemd/system/studytracker.service.d
sudo tee /etc/systemd/system/studytracker.service.d/exam-integrity.conf <<'EOF'
[Service]
Environment=EXAM_INTEGRITY_DISABLED=1
EOF
sudo systemctl daemon-reload
sudo systemctl restart studytracker
sudo systemctl is-active studytracker
curl --fail --silent --output /dev/null http://127.0.0.1:5002/login
```

保持 gunicorn 单 worker、gthread、6 threads、5002。恢复时在同一专用 drop-in 中改为 `Environment=EXAM_INTEGRITY_DISABLED=0`，再执行 daemon-reload/restart；也要经过无考试确认。恢复后先核每场策略，原来开启的策略可能重新生效。

老师面板仅为诚信功能创建三张新表。学生请求不建表；缺表、查询失败时按关闭处理。若需人工建表，由维护人员备份数据库并核实路径后运行（不导入 app）：

```sh
cd /root/apps/studytracker
.venv/bin/python scripts/create_exam_integrity_tables.py --database /root/apps/studytracker/app.db --dry-run
.venv/bin/python scripts/create_exam_integrity_tables.py --database /root/apps/studytracker/app.db
```

只创建新表，不 ALTER 现有表。回滚可保留新表；不删考试记录、不重算成绩。不要在生产为验证故障而删表。

## 对学生启用前：真机验收单

部署许可不等于允许直接对学生开启锁定。先新建不含真实学生数据的试考，在 iPad Safari、MacBook Safari、MacBook Chrome 分别填写结果，记录系统／浏览器版本。

| 场景 | iPad Safari | Mac Safari | Mac Chrome |

| 外部作文粘贴／拖入被拦，内部剪切粘贴可用 | 待验 | 待验 | 待验 |

## 官方资料核对（2026-11-14）

- [Apple 引导式访问](https://support.apple.com/zh-cn/111795)：设置→辅助功能→引导式访问；顶部或主屏幕按钮连按三次启动；选项名称随系统为“会话设置”或“选项”。当前官方选项没有单独“关闭词典查询”；不将计划中的这一步当作已验证功能。锁住的是 App，Safari 内标签和查词限制须真机核验。
- [WebKit Safari 16.4](https://webkit.org/blog/13966/webkit-features-in-safari-16-4/)：提供 Screen Wake Lock，iPadOS 16.4 起可尝试。实现用能力检测，拒绝和释放均静默，不承诺避免所有自动锁屏。
- [SEB Config Key 官方文档](https://safeexambrowser.org/developer/seb-config-key.html)：现代 WKWebView 不发送 CK/BEK 请求头，需 JavaScript API；后续实施不可仅靠 UA 或请求头声称强校验。配置与实际 URL 的绑定、版本、反向代理原始 URL 必须另测。
- [SEB iOS 官方手册](https://safeexambrowser.org/ios/ios_usermanual_en.html)与[官方下载](https://safeexambrowser.org/download_en.html)：配置可通过 `.seb` 和 `sebs://` 分发，须先用官方工具制作并验证退出路径。本期只给下载与说明，不提供假配置或无效“打开考试”按钮；正式集成独立阶段验收。
